FINIX Transaction Risk Score Dataset Specification v3.0 (FINAL)
1. Objective
Develop a Transaction Risk Score model to identify potentially fraudulent banking transactions using transactional, behavioural, device, session, location and historical features. The model outputs a transaction risk score and fraud prediction.

14. Target Label
is_fraud0 = Genuine Transaction1 = Fraudulent Transaction
15. Fraud Behaviour Injection
High-value transaction anomaly
New recipient transfers
Rapid transaction velocity
Impossible travel
Multiple failed PIN attempts
Late-night unusual transactions
Structuring (multiple similar-sized transfers)
Transactions to high-risk recipients (RecipientGNNScore)
16. Noise Injection
1% Missing merchant category
2% Timestamp jitter
2% GPS drift
1% Missing device information
3% Transaction amount variation
